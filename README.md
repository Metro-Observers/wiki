# Википедия игрового проекта

Официальная вики и документация для нашего игрового сервера. Здесь собраны все правила, руководства, описания ролей и другая важная информация для участников.

## Быстрый старт

Вики опубликована на GitHub Pages и доступна по ссылке:  
👉 **[https://metro-observers.github.io/wiki/](https://metro-observers.github.io/wiki/)**

## Структура проекта

*   `index.html` - Главная страница
*   `resources` - Изображения для страниц
*   `resources/styles.css` - Основные стили
*   `pages/` - HTML-страницы разделов вики (Новичкам, Правила, Роли и т.д.)
*   `fractions/` - HTML-страницы различных фракций (категорий) для облегченной ориентации по ролям
*   `roles/` - HTML-страницы для подробного описания роли

## Особенности

*   **Статический сайт** — Быстрая загрузка, не требует серверной части
*   **Адаптивный дизайн** — Корректно отображается на ПК, планшетах и телефонах
*   **Тёмная/светлая тема** — Переключение между темами с сохранением выбора
*   **Чистая структура** — Легко редактировать и добавлять новый контент

## Для редакторов

Вы можете добавить новую страницу, просто создав PR или вступив в отдел Wiki-редакторов.

## Редактор (CMS)

Правки ролей можно делать в браузере, без ручного HTML:

1. Открой [CMS](https://metro-observers.github.io/wiki/admin/).
2. Войди через **Sign in with GitHub token** (fine-grained PAT на репозиторий `Metro-Observers/wiki`: Contents + Pull requests = Read and write).
3. Правишь поля роли → **Save** → Sveltia открывает **pull request** в `main` (editorial workflow).
4. GitHub Action `Render role pages from CMS` пересобирает HTML из `content/roles/**/*.yml`.
5. После ревью мержишь PR — Pages обновляет сайт.

Исходники ролей: `content/roles/`. Собранные страницы: `roles/`. Локально: `python scripts/render_roles.py`.
